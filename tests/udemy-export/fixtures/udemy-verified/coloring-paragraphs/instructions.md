# Coloring Paragraphs

## Instructions

The HTML below already has four paragraphs with **ids** and **classes**. Your job is to color them with CSS `background-color`.

- `#title` — background **yellow**
- `.intro` — background **lightblue**
- `#main` — background **orange**
- `.footer` — background **pink**

Use id selectors (`#…`) and class selectors (`.…`). Named colors like `yellow` are fine — you do not need hex codes. Keep your CSS syntactically valid (matching braces, real property names and values).
