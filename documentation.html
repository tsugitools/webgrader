WebGrader Help

WebGrader is an interactive browser autograder for introductory HTML (and later CSS and JavaScript).

Learner workflow

  1. Read the assignment prompt.
  2. Edit the source in the editor tabs.
  3. Press Run / Restart to load your page in the preview.
  4. Interact with the preview if the assignment asks you to.
  5. Press Grade to check your work and send a score.

If you edit source after Running, Grade stays disabled until you Run again so the grader always sees the code you last previewed.

The Console panel shows console.log / warn / error output, uncaught JavaScript errors, and failed resource loads (<img>, scripts, etc.) from the preview. It clears on each Run / Restart. Messages from the surrounding Tsugi page or the browser Network panel are not mirrored here.

Some assignments also check that your HTML or CSS source validates (optional html_validate / css_validate tests). Fix any reported issues and Grade again.

Instructors

If the assignment includes a reference solution, instructors see a Load solution button in Learner view. It fills editable editors with the solution (readonly tabs are left alone) so you can Run and Grade it. Re-select the built-in from Settings (or use Import JSON) if an older placement copy is missing the solution field.

In Edit mode, assignment instructions use a rich text editor (CKEditor), same pattern as other Tsugi tools. Saved HTML is sanitized when shown to learners.

Reset and autosave

Your source is autosaved for this placement. Use Reset to starter to discard your work and restore the assignment starter code.

Security note

Student pages run in a same-origin iframe so the grader can inspect the DOM. This is an educational environment, not a hostile-code sandbox. Infinite loops in student JavaScript can freeze the browser tab; use Run / Restart to rebuild the preview after fixing the code.
